# Contact Manager CLI

A **simple and interactive Contact Manager** built with **Python**.  
Store, view, delete, and search contacts easily from the command line.

---

## Features

- Add new contacts (Name, Age, Email)
- View all saved contacts
- Delete contacts by selecting from the list
- Search contacts by name
- Data stored locally in `contacts.json`
- Interactive and user-friendly CLI with emojis for better readability

## Requirements

- Python 3.x
- No external libraries required

---

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/ContactManager.git
cd ContactManager
```
2. Run the program:

        python main.py

3. Follow the menu to manage your contacts.

---

**Usage Instructions**

- **Add contact:** Input name, age, and email to add a new contact.

- **Show contacts:** View all saved contacts in a formatted list.

- **Delete contact:** Remove a contact by choosing its number from the list.

- **Search contact:** Find contacts by entering a part of the name.

- **Exit:** Close the program safely.

---

**Data Storage**

- All contacts are stored locally in (`contacts.json`) in JSON format.

- No encryption is used, so keep the file safe if storing sensitive info.
